1. Кто мы

AdPilot («мы», «сервис») — AI-платформа для автоматического создания и запуска рекламных кампаний в Meta (Facebook, Instagram) через Telegram-бот. Оператор: ИП Гавел Станислав. Контакт: @sgabelev

2. Какие данные мы собираем

  • Идентификационные данные: Telegram ID, имя пользователя, имя в Telegram
  • Бизнес-анкета: описание бизнеса, целевая аудитория, гео, бюджет, цели рекламы
  • Meta данные: токен доступа к рекламному кабинету Meta (хранится в зашифрованном виде), ID рекламного кабинета, ID страницы Facebook
  • Данные кампаний: созданные объявления, результаты A/B тестов, метрики эффективности
  • API ключ: ключ OpenRouter для доступа к AI-моделям (хранится в зашифрованном виде)

3. Как мы используем данные

  • Генерация рекламных текстов с помощью AI (Claude, Gemini, GPT-4)
  • Создание и управление кампаниями через Meta Marketing API
  • Анализ эффективности кампаний и авто-оптимизация
  • Улучшение качества генерации (анонимизированные паттерны по нишам)
  • Техническая поддержка

4. Передача данных третьим сторонам

Для работы сервиса мы взаимодействуем с:

  • Meta Platforms (Facebook, Instagram) — для создания и запуска рекламных кампаний
  • Anthropic (Claude) — для генерации и оценки рекламных текстов
  • Google (Gemini) — для генерации вариантов объявлений
  • OpenAI (GPT-4) — для генерации вариантов объявлений
  • OpenRouter — API-маршрутизатор для AI-моделей

Мы не продаём и не передаём ваши личные данные третьим сторонам в коммерческих целях.

5. Хранение данных

Данные хранятся на защищённых серверах в ЕС. Токены доступа хранятся в зашифрованном виде. Вы можете запросить удаление всех данных в любой момент через поддержку: @sgabelev
